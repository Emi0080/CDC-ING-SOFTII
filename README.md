# Campus Digital Companion (CDC)Campus Digital Companion (CDC)
## DescripciónDescripción
Campus Digital Companion (CDC) es una iniciativa de transformación digital impulsada por la Universidad NovaTech para mejorar la experiencia académica de los estudiantes mediante una plataforma digital centralizada.

El proyecto busca proporcionar herramientas que faciliten la organización personal, la participación estudiantil y el acceso a información relevante dentro del ecosistema universitario.
 
## Estado del Proyecto

Versión actual: Piloto Institucional

Estado: Operativo con funcionalidades limitadas

Nivel de madurez: En evolución

 
## Objetivos Iniciales

•	Facilitar la organización académica.

•	Mejorar la comunicación institucional.

•	Incrementar la participación estudiantil.

•	Centralizar información relevante para los estudiantes.

•	Modernizar los servicios digitales universitarios.

 
## Funcionalidades Disponibles

Gestión Personal

•	Creación de tareas

•	Edición de tareas

•	Seguimiento de actividades

Eventos

•	Consulta de eventos académicos

•	Filtrado por categorías

•	Gestión básica de perfil

Notificaciones

•	Recordatorios

•	Comunicaciones institucionales
